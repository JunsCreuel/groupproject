기획 배경

왜 CSL인가

  • 현대인의 스트레스 해소 방식: 왁뿌볼을 비롯한 오감 활용 스트레스 해소
  • 술, 담배, 무한 스크롤 같은 회피성 해소의 문제
  • 촉각 놀이, 반복 행동, 즉각적 자극이 주목받는 이유

1. 문제 정의

  • 기존 스트레스 서비스는 명상, 기록, 정보 제공에 치우쳐져 있음
  • 실제로 무언가 하고 싶은 충동을 풀어주는 사이버 공간의 부재

2. 핵심 컨셉

  • 스트레스를 참는 대신 안전하게 발산하자!
  • 직접 클릭, 드래그, 키보드 입력 등으로 해소

3. 예상 사용자

  • 스트레스 상황에서 즉각적으로 행동을 실천할 수 없는 사람들
  • 짧고 즉각적인 스트레스 해소를 원하는 사용자
  • 감정 기록이나 명상과 같은 정적인 방법보다 놀이형 인터랙션을 선호하는 사용자
